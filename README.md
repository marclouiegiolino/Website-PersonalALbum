# Website-PersonalAlbum

A full-stack romantic photo album application.

## Project Structure

```
Website-PersonalALbum/
├── backend/    # Express + Prisma + SQLite API server
└── frontend/   # Next.js interactive flip-book frontend
```

## Getting Started

### 1. Backend Setup
```bash
cd backend
npm install
npm run db:push
npm run dev
```
Backend runs on `http://localhost:4000`.

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Frontend runs on `http://localhost:3000`.
